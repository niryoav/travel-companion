# Design system

The design system should remain simple and practical during Sprint 0.

## Direction
- Mobile-first layout.
- Calm typography and strong contrast.
- Clear cards, sections, and spacing.
- Status communicated with text and structure, not colour alone.
- Subtle motion only where it supports clarity.

## Initial foundations
- Use semantic HTML and accessible labels.
- Favor reusable components over one-off UI patterns.
- Keep visual language warm, premium, and understated.
- Treat the current mock-up as inspiration, not a final specification.
